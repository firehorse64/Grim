GRIM LINE — Custom 3D Model Guide
====================================

Place .glb files in this directory to replace the procedural box characters.

SUPPORTED FILES:
  player.glb  — Replaces the player character
  zombie.glb  — Replaces all zombies
  npc.glb     — Replaces NPCs (like Sarah)

REQUIREMENTS:
  - Format: GLB (binary GLTF)
  - Feet at local Y=0
  - Facing +Z direction (forward)
  - Roughly 1.3 units tall (to match the game world scale)
  - If your model is too big/small, scale it in Blender before export

ANIMATIONS (optional, embedded in the .glb):
  idle    — Standing still / breathing
  walk    — Walking forward
  attack  — Melee attack / lunge
  death   — Death animation (for ragdoll replacement)
  crawl   — Climbing through window (zombie only)

  Animation names are case-insensitive.
  If an animation is missing, the system falls back gracefully.

HOW TO CREATE MODELS:
  1. Open Blender (free: blender.org)
  2. Model your character
  3. Add an Armature (skeleton) for animations
  4. Create animation Actions named: idle, walk, attack, etc.
  5. File > Export > glTF 2.0 (.glb)
     - Format: GLB
     - Check "Include > Animation"
     - Uncheck "Include > Camera" and "Include > Punctual Lights"

FREE MODEL SOURCES:
  - Mixamo (mixamo.com) — Free rigged humanoids with animations
    1. Upload or pick a character
    2. Browse animations, download each one
    3. In Blender: import FBX, rename actions, export as single .glb
  - Sketchfab (sketchfab.com) — Many free GLTF models
  - Kenney (kenney.nl) — Simple game-ready characters
  - Quaternius (quaternius.com) — Free low-poly packs

TESTING:
  Just drop a .glb file here and refresh the game.
  Check the browser console for "[ModelLoader] Loaded: /models/player.glb"
  If no file is found, the procedural box character is used automatically.
